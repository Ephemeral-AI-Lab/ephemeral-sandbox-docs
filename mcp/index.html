MCP calling manual

Arguments are JSON fields—not CLI flags. The server forwards a validated operation request through the authenticated gateway.

01

Pick the server

Use Management for host/fleet ownership, Runtime for command and file operations, and Observability for read-only inspection.

ephemeral-os-management ephemeral-os-runtime ephemeral-os-observability
02

Call a tool

Put only documented fields inside params.arguments. Unknown properties are rejected before gateway dispatch.

JSON-RPC request
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "list_sandboxes",
    "arguments": {}
  }
}
03

Read the result

Machine-readable operation data is returned in result.structuredContent. Check result.isError before consuming it.

Success envelope
{
  "result": {
    "content": [{ "type": "text", "text": "…" }],
    "structuredContent": { "sandboxes": [] },
    "isError": false
  }
}

Guardrails

Know the state boundary before calling.

Read-only

Observe freely

All Observability tools, plus Management discovery and inspection and Runtime file_read/file_blame, do not intentionally mutate sandbox state.

Session state

Commands can publish

exec_command without a workspace session automatically captures and publishes changes when the command reaches terminal state.

Mutating

Require intent

Creation, destruction, squash, export, file writes, file edits, and command input can change host or sandbox state. Review their manuals first.
