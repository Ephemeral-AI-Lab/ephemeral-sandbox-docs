What an RL rollout contains

Environment work becomes training data.

A rollout is one sampled trajectory: the model observes state, chooses actions and tool calls, receives verifier rewards, and records the full trace. Many trajectories form a batch for PPO, GRPO, or another policy update.

01 / Fork

Snapshot state

Mount the same immutable base into each isolated environment and allocate an empty private upper layer.

02 / Sample

Run the policy

Give each environment a prompt, seed, or temperature. The agent emits tokens, commands, edits, and tool calls.

03 / Transition

Execute actions

The sandbox mutates only its own COW delta. New observations return to the policy for the next step.

04 / Verify

Score outcomes

Tests, judges, constraints, and task-specific verifiers turn terminal state and trace quality into rewards.

05 / Collect

Store trajectories

Persist observations, actions, log probabilities, rewards, tool outputs, and termination reasons.

06 / Learn

Update the policy

Compute advantages across the batch, optimize the objective, publish a checkpoint, and roll out again.

Two COW rollout modes

Same invariant, different isolation cost.

Both modes keep one physical base payload. Choose separate sandboxes for a stronger failure boundary; choose sessions inside one sandbox when startup density matters more.

MODE A / CONTAINER BOUNDARY

N parallel sandboxes

Every rollout gets a container, daemon, scratch volume, and layer-stack volume. Docker image layers and the content-addressed workspace base volume are shared.

From prototype to credible proof

Measure bytes, not labels.

The HTML model communicates the architecture. The live demo should replace its estimates with physical allocated bytes, launch latency, isolation checks, and cleanup evidence from the real system.

Recommended benchmark sequence

Hold the base constant. Scale only rollout count and deliberate writes.

Write exactly 10 MB per rollout. Total private storage should track N × 10 MB plus overhead.

Destroy every rollout, run cleanup, and show private bytes return near the baseline.
