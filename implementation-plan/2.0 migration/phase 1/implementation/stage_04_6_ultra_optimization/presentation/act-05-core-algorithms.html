Architecture/Algorithms
Act 05 · Cost model

Make work follow the delta

MPLA combines established primitives—content addressing, persistent Merkle trees, content-defined chunking, external sorting, and OCC—with a novel stationary ownership protocol.

No one algorithm removes all cost. The design works because each algorithm attacks a different amplification: copy, heap, hashing, transfer, or mount depth.

Algorithm 01 · Ownership

Stationary adoption removes the second H

The upper already contains every newly written byte. After sealing proves immutability, changing its owner is sufficient to make it a durable locator.

Algorithm 03 · Canonical update

Only paths to changed leaves are rebuilt

A persistent Merkle tree reuses every unchanged subtree. Changing one file creates a new leaf and new ancestors to the root; siblings remain shared.

work ≈ affected paths × Merkle depth d

The exact bound also depends on directory fan-out, metadata changes, renames, and the number of distinct affected ancestors.

Why total existing size often stops mattering: when mutation evidence is complete and changed payloads are small, neither unchanged 10 GiB payload bytes nor unchanged subtrees are rewritten.
Fallback caveat: incomplete evidence may require scanning a larger subtree or the full upper to prove what changed.
Algorithm 04 · Large files

Content-defined chunking reuses stable chunks around a tiny edit

Chunk boundaries follow content rather than fixed byte offsets. An insertion shifts local boundaries, then the stream resynchronizes so later chunks can retain their payload IDs.

Algorithm 05 · Runtime selection

Projection reuse turns activation into a decision tree

A stored exact receipt removes repository-size work from the readiness path. A miss preserves the same semantic result but pays the physical floor.

Notation that prevents confusion

Merkle depth and projection depth describe unrelated structures

The old discussion often blended them because both can be drawn as trees or stacks.

Is MPLA novel? The ingredients are established. The creative contribution is their boundary discipline and the seal–adopt–rotate protocol that turns an active OCI upper into backend-neutral durable payload state without coupling canonical identity to OverlayFS.
